# voice-notes：錄音 → 逐字稿 → 整理文件（全本機）

把一段錄音轉成逐字稿、再整理成一份可讀的繁體文件。**轉錄與整理全在本機完成，音檔不外送**
（模型是一次性從網路下載進來）。

## 前置：找到本機引擎
轉錄引擎是裝在本 skill 資料夾下的 Python venv。以本 SKILL.md 所在資料夾為基準：
- Windows：`<skill>\.venv\Scripts\python.exe`
- macOS / Linux：`<skill>/.venv/bin/python`

若該 venv 不存在 → 代表還沒安裝，請提示使用者執行 repo 根目錄的 `install.ps1`（Windows）或
`install.command`（Mac），然後重開 session。

## 流程

### 1. 取得錄音檔路徑
從使用者訊息拿到音檔路徑。拿不到就問一句「錄音檔在哪個路徑？」。

### 2. 轉逐字稿（跑本機引擎）
用上面的 venv python 執行 `transcribe.py`：

```
<venv-python> <skill>/transcribe.py "<音檔路徑>"
```

- 預設模型 `large-v3`、語言 `zh`（中文夾英文適用）。
- 嫌慢可加 `--model medium`（或 base/tiny）；想自動偵測語言加 `--language ""`。
- **stdout 會印出逐字稿檔路徑**（通常是音檔旁的 `<名稱>.txt`），進度在 stderr。
- 首次使用某模型會下載（large-v3 約 3GB），時間較久屬正常；跑完再往下。

### 3. 讀逐字稿、判斷整理類型
讀第 2 步產出的 `.txt`。依使用者指定或內容判斷要整理成哪一種（範本見
`references/templates.md`）：
- 多人對話／開會 → **會議記錄**
- 訪談／上課／講解 → **重點筆記**
- 個人口述／備忘 → **條列整理**

使用者沒指定、內容也難判時，問一句要哪一種（給預設建議）。

### 4. 整理成繁體文件
依範本把逐字稿整理成文件，必做：
- **簡轉繁 + 台灣用語**（Whisper 中文常吐簡體；在途→進行中、信息→訊息…）。
- **補標點、分段**（逐字稿常無標點）。
- **結論先行**；表格用 Markdown（可直接貼 TG/Excel）。
- 忠實保留內容細節，別自行濃縮重要資訊。

輸出 `.md` 存在**錄音檔同資料夾**，檔名 `<音檔名>-整理.md`。

### 5. （可選）出 PDF
使用者要 PDF 且本機有 playwright → 走 HTML+CSS→PDF（參見團隊 `reference_html_to_pdf` 做法）。
沒有 playwright 就只給 `.md`、別報錯，並告知可自行安裝後再出 PDF。

### 6. 開檔給使用者看
產出後直接開：Windows `start "" "<檔>"`、macOS `open "<檔>"`。

## 原則
- 全程本機離線；**絕不把錄音/逐字稿內容送到外部服務**。
- 逐字稿原檔（`.txt`）可能是簡體，屬中間產物；交付的整理文件一律繁體。
- 一段錄音 → 一份逐字稿 → 一份整理文件，落在錄音檔旁，路徑清楚。
